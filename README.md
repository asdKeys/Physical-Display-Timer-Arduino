# [ARDUINO]Experimental

## About

It's experimental.

## How to Use

First, download the Arduino IDE if you don't have it. Then, go to the file called "4_DIGIT_7_SEGMENT_DISPLAY_MINUTES_SECONDS.ino" and copy and paste that into the Arduino IDE. The wiring is listed below with a diagram.

## Building

### Parts Needed

- Any Arduino board.
- A breadboard.
- A 4 digit 7 segment LED display.
- A button.
- A buzzer.
- 8 220 ohm resistors.
- 1 10K ohm resistor.
- 31 wires.
